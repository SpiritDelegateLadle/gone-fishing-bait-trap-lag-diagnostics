## 🛠️ Troubleshooting — Step by Step

1. **Install the newest patch.** The October 28 update addressed severe bait-trap lag. Check whether the problem reproduces on the latest version.
2. **Create a comparison.** Measure performance once in an empty area and once beside active bait traps.
3. **Reduce variables.** Temporarily deactivate or reduce active traps, then retest one change at a time.
4. **Check the graphics load.** Compare the same area at a reduced graphics preset and monitor whether frame pacing improves.
5. **Report persistent regressions.** Capture game version, trap count, GPU/CPU and a short reproduction sequence.
